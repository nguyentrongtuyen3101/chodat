# POD Design – giao diện mô phỏng và sơ đồ

- `pod-design-ui/`: giao diện HTML thuần (site quản lý + site bán hàng) của hệ thống backend quản lý thiết kế và cá nhân hóa sản phẩm POD. Mở `pod-design-ui/index.html` để xem.
- `so-do-drawio/`: các sơ đồ UML dạng `.drawio` (XML), mở bằng https://app.diagrams.net hoặc draw.io desktop.
